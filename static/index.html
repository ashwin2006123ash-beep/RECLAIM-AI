RECLAIM AI 2.0 — Architecture & Civic AI Guardrails

SYSTEM ARCHITECTURE

RECLAIM AI 2.0 is engineered strictly for the Agentic AI Hackathon 2026 — Powered by Ziro.Digital under the Social Impact & Sustainability AI track. It unifies 5 core innovations into a single coordinated agent loop.

1. Observe & Intake

Collects case attributes without storing real Aadhaar/PAN or sensitive PII.

2. Recovery Twin

Constructs dynamic dependency graph with real BLOCKED / READY / COMPLETED states.

3. Proof-of-Truth Vault

Mines statutory claims, assigns provenance tags, and resolves conflicting circulars.

4. Adaptive Planner

Compares Route 1 (DigiLocker), Route 2 (Statutory Portal), and Route 3 (Counter).

5. Risk Radar

Detects predatory brokers, SSRF, fee anomalies, and missing police reports.

6. Safe Sandbox

Simulates submission with idempotency keys and independent verification.

Technology Stack & Design Choices

Backend: Python 3.13, Flask REST API, SQLite parameterized database, Google Gemini Interactions API (with deterministic offline civic reasoning fallback).
Frontend: Native Vanilla ES6 modules, CSS3 civic tech design system with dark navy palette, glassmorphism, responsive CSS grid/flexbox, accessibility tags.
Security: SSRF protection, URL sanitizer, zero-PII storage policy, idempotency keys, and explicit Human-in-the-Loop gates.
